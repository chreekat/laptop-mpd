# dcs-mpd

Pixels flow Windows -> Thinkpad only. DCS, the virtual display, and Sunshine
run on the Windows machine; the Thinkpad (NixOS, `kuusi`) runs Moonlight
fullscreen and nothing else of ours. Keep that split in the layout described
in README.md. The global rules above come from a `dotfiles` checkout beside
this one.

Anything about DCS internals (viewport names, Lua hooks, option semantics) is
verified by reading the DCS install on the Windows machine, not from forum
memory. Cite the file path when recording such a fact in PLAN.md or README.md.
